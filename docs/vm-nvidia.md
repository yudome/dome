# NVIDIA VM backend

TLDR: `backend=auto` uses Conduit on an NVIDIA host when it can, otherwise the QEMU GL path.

## Check

```bash
yudae vm doctor          # human JSON
vm/doctor                # human
xmake doctor             # host checks + vm/doctor
```

Each failing check prints a fix. Agents run `yudae vm doctor`, not install commands.

## Backends

- `nvidia`: Conduit backend + `conduit-guest` + patched QEMU, real host GPU.
- `gl`: current virtio-gpu/virgl path.
- `auto`: NVIDIA if the capability probe passes, else GL. `--gl` forces GL.

The NVIDIA guest has no virtio-gpu. Its compositor uses `/dev/dri/card*` from the
Conduit module; `yudae-session` selects the card from `/dev/dri/by-path`.

## QEMU

The source fork is `yumedots/qemu-linux`, `main` = QEMU v11.1.2 + Conduit's nine
patches as commits. Built binary: `~/qemu-linux/install/bin/qemu-system-x86_64`.
Override with `YUDAE_NVIDIA_QEMU`.

## ABI

620.70.06 tables live in `yumedots/conduit` from Conduit's generators. New
releases are generated by Conduit's weekly ABI workflow; run its generator when
the host driver is newer. `conduit-backend --allow-nearest-abi` covers the escape
table when an exact release table is not available.

## Golden image

`vm/packages.txt` is the explicit guest manifest. Build:

```bash
xmake vm packages --snapshot 2026/11/01 --force
xmake vm golden --snapshot 2026/11/01
```

The golden setup installs `conduit-guest`, matching headers, the NVIDIA mount,
the GBM link and `yudae-session`.

## Display

`yudae vm view` opens the VM app, whose `VmDisplay` item implements the broker
side of the Conduit display protocol (`shell/native/src/brokerdisplay.cpp`):
it listens on the backend's `display-nvidia.sock`, sends `EV_HELLO`/`EV_SURFACE`
and input events, and imports each ATTACH dma-buf with EGL zero-copy. One 40-byte
command per `recvmsg` keeps the SCM_RIGHTS fd bound to its ATTACH.

The external `conduit-viewer` is only a manual fallback; it is not started by
`yudae vm view`. `vm screenshot` uses guest `grim`, so it works without a viewer.
